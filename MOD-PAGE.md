# Unlock All Backgrounds

*For the people like myself who will never finish all of the endings.*

Unlocks every main menu background the moment you install it, and adds live
Tarkov's **Server Room** background. No new profile, no config, nothing to grind.

That covers the six vanilla backgrounds, including Cyber and The Unheard
Edition, which a normal profile never gets. It also covers any background another
mod adds. If you run WTT-ContentBackport, Hotline Tarkov and the four ending
backgrounds get unlocked too.

**Server Room** is the live server room panorama, with the animated radio that
clicks through its menus and takes the odd incoming call. It's amos's
[Server Room Backport](https://github.com/14amos/ServerRoomBackground), included
with their permission. Thanks, amos!

**It never touches your profile.** Nothing is written to your save. Uninstall and
the backgrounds go back to locked, with nothing left behind to clean up.

## Install

1. Close the game and the SPT server.
2. Extract the zip into your SPT folder (the one with `EscapeFromTarkov.exe`).
3. Start the server, then the game.
4. Pick a background in **Settings → Game**.

**Fika:** every player needs the mod installed, not just the host.

**Already have Server Room Backport?** You can remove it, or keep it; this mod
steps aside for it.

## Uninstall

Delete the three `UnlockAllBackgrounds` folders:

- `BepInEx\plugins\UnlockAllBackgrounds`
- `BepInEx\patchers\UnlockAllBackgrounds`
- `SPT_Runtime\user\mods\UnlockAllBackgrounds`
